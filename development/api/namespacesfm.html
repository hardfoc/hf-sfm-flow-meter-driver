◆ SupportsGas()

constexpr bool sfm::SupportsGas ( Variant v,
Gas g )
constexprnoexcept

Whether a variant carries a factory calibration for g.

SFM4300-50-x: O2, Air, Air/O2 mixture only (Table 16). SFM4300-20-x: the seven SF06 tables. SFM6000D-x: O2, Air, CO2, N2O, Ar and O2-in-Air. Unknown variants: O2 and Air only — every other start code means a different gas (or none) on the other family, so it is refused until the identity is read (see GasNeedsKnownFamily).
