Detailed Description

I2C command codes, addresses, timing and CRC-8 for Sensirion flow meters: the SF06 family (SFM4300 data sheet §4) and the SFx6000 family (SFC6xxx / SFM6xxx I2C interface reference v1.1).

Framing (16-bit commands, word + CRC-8 reads) is shared by both families. Gas meaning of the start codes is not: 0x3615 is N2O on SF06 and CO2 on SFx6000, 0x361E the reverse. Never use these constants directly to pick a gas — go through StartCommandFor(Family, Gas) in sfm_types.hpp. Checksum is CRC-8, polynomial 0x31, init 0xFF, no reflection, no final XOR; test vector 0xBE 0xEF → 0x92.
