HF-SFM driver documentation

This site mirrors the docs/ folder in the repository and documents the Sensirion SF06 I²C command set (SFM4300 data sheet §4) as implemented by this header-only driver. The same command set is shared by SFM3003, SFM3013, SFM3019 and SFM3119.
