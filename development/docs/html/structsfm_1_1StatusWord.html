Detailed Description

Decoded status word (data sheet §4.3.2, Table 5).

bits 15:12 — currently running measurement command (0b0000 O2 … 0b0110 CO2/O2), bit 11 — exponential smoothing active (avg-until-read idle > 64 ms), bit 10 — fixed-N averaging active, bits 9:0 — gas fraction (‰) or 0x3FF for pure gas.
