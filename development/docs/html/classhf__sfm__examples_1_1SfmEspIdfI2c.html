Detailed Description

template<i2c_port_t kPort, int kSdaGpio, int kSclGpio, std::uint32_t kSpeedHz = 400000U, std::uint32_t kTimeoutMs = 20U>
class hf_sfm_examples::SfmEspIdfI2c< kPort, kSdaGpio, kSclGpio, kSpeedHz, kTimeoutMs >

Template I2C bridge: one concrete type per (port, SDA, SCL, speed) tuple.

Call Install() once before constructing sfm::Driver<SfmEspIdfI2c<...>>. SF06 parts support 400 kHz (default here) up to 1 MHz Fm+. Pull-ups required.
