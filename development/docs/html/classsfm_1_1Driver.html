Decode one 9-byte continuous-mode frame (3 × word + CRC).

Pure: the same decode serves the blocking read above and an interrupt / DMA reader that fetched the frame itself. SF06: flow, temperature, status. SFx6000: flow, reserved, status (temperature through ReadTemperature()).

◆ StartContinuous()

template<typename I2cT >
DriverResult< void > sfm::Driver< I2cT >::StartContinuous ( Gas g,
uint16_t o2_permille = 0 )
inlinenoexcept

Start continuous measurement for g (§4.3.1).

Reads the gas table scaling first (so ReadMeasurement() can convert), refuses gases the known variant does not calibrate, then issues the start command and waits timing::kFirstResultAfterStartMs.

Parameters
gGas or mixture.
o2_permilleO2 volume fraction for mixtures (ignored for pure gases).
