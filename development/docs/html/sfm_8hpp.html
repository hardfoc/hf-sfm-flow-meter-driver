Detailed Description

Umbrella header for the HF-SFM (Sensirion SF06-family) flow-meter driver.

Pulls in sfm::I2cInterface, command codes and CRC-8, typed readings (Measurement, Scaling, ProductInfo, StatusWord), and sfm::Driver<I2cT> implementing the SFM4300 data sheet §4 command set. See examples/esp32/ for an ESP-IDF I2C adapter.
